# Story 2.10.2 evidence: terms explain themselves where they are

Band 2.10. Recorded by the build session on 9 September 2026. Nothing here is
carried across from band 2.7.

---

## 1. What the story replaces

Story 2.7.5 shipped a glossary and a test proving every specialist term on the
screen was defined. The test proved coverage, not comprehension. A reference a
planner does not open is not an explanation, and seven terms were still unread.

Each of the seven now says what it means where it appears. Not a link, not a
page the reader leaves for.

## 3. One source, still

The interface carries a slug and an empty placeholder. `renderGlosses()` fills
every placeholder from the glossary payload fetched once from `/api/glossary`.
No definition is written into `static/index.html`, which
`test_no_definition_is_written_in_the_interface` has enforced since 2.7.5 and
still does. The screen and the report's method appendix cannot drift.

Four definitions were added to `glossary.py`, because four of the seven had
nothing to render:

- **Accept**, **Accept with warnings**, **Reject**, a new `File verdict` group.
  A file verdict is defined as a file verdict, so it cannot be read as a
  verdict on the lines.
- **Croston family**, a new `Forecasting method` group. The routing reason that
  names it is engine copy pinned by `expected_routing.json`, so the word cannot
  be reworded and had to be explained underneath instead.

## 4. One thing deliberately not done

**The NOT USABLE DATA pill carries no gloss.** Every quality band in the
glossary is defined for a line, beginning "This line's history". That pill
labels the portfolio. Attaching the line definition to it would state something
false on the screen, which is worse than leaving it unexplained for one story.

Saying what that label applies to is story 2.10.3, the next one, and it is that
story's acceptance criterion word for word. `test_the_band_pill_is_left_to_the_story_that_owns_its_scope`
records the decision so it cannot be lost.

## 5. The 2.7.6 height rule

2.7.6 was accepted on "the default screen is no longer than it is today". That
still holds and was not softened. The workspace is hidden until a file is
assessed, and the verdict placeholder is empty until a verdict exists, so the
landing screen a stranger sees is byte for byte what it was. The glosses cost
height only inside a completed run, which is where 2.10.2 requires them.
