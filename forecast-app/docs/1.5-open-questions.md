# Story 1.5 open questions

Status: the technical controls are implemented. One provider assurance item remains open.

## Q1. May the manifest contain the uploaded filename?

Decision: no. Manifest version 1.3 and later record `filename_sha256` and extension only. Legacy version 1.2 remains readable and can contain a filename.

## Q2. Where may confidential bundles reopen?

Decision: in the browser only. The server reopen route was removed. Reopening renders recorded values and calls no engine.

## Q3. What may application logs contain?

Decision: fixed operational messages and platform request metadata only. Do not deliberately log filenames, source rows, SKUs, findings, request bodies, bundle contents or client-facing exception text.

## Q4. Can BigQuery return a cached forecast?

Decision: no. Query caching is disabled and the provider fails closed if job metadata reports a cache hit.

## Q5. Where does managed forecasting run?

Decision: `europe-west2`, with Vercel functions in London. Preview and Production were corrected and verified during Story 1.5 acceptance.

## Q6. Is there an unqualified no-retention claim?

Decision: no. Application code does not deliberately save uploads, but multipart handling can spool temporarily and BigQuery anonymous query results can remain available under provider lifecycle rules.

Open item: obtain written provider confirmation on the scope of platform backups, then complete qualified legal and contractual review before making a stronger client statement.
